## About SDC SNIST

**Student Developers Community (SDC SNIST)** is a student-driven developer community at Sreenidhi Institute of Science and Technology, focused on helping students gain practical skills in software development, artificial intelligence, and emerging technologies.

We organize:

-  Hackathons
-  AI Workshops
-  Developer Bootcamps
-  Tech Events
-  Networking Sessions

## 🚀 Getting Started

1.  **Install Dependencies**:
    ```bash
    npm install
    ```
2.  **Run Development Server**:
    ```bash
    npm run dev
    ```
3.  **Open in Browser**: [http://localhost:3000](http://localhost:3000)
